RISK ESPAÑA — PROTOTIPO WEB

IMPORTANTE
El archivo debe servirse desde una página web HTTPS. La vista previa de algunas aplicaciones de archivos (por ejemplo, DS file) bloquea JavaScript y deja el mapa vacío.

PUBLICAR CON GITHUB PAGES
1. En un ordenador o navegador, inicia sesión en GitHub y crea un repositorio público llamado risk-espana.
2. Sube el archivo index.html de esta carpeta a la raíz del repositorio.
3. En el repositorio, abre Settings > Pages.
4. En Build and deployment, elige Deploy from a branch.
5. Selecciona la rama main y la carpeta /(root), y guarda.
6. Espera a que GitHub publique el sitio. La URL tendrá el formato:
   https://TU-USUARIO.github.io/risk-espana/
7. Abre esa dirección en Safari en el iPad. Para añadirlo a la pantalla de inicio:
   Safari > Compartir > Añadir a pantalla de inicio.

NOTAS
- Este prototipo todavía utiliza un mapa esquemático y reglas simplificadas.
- El modo local está pensado para turnarse en el mismo dispositivo.
- El guardado utiliza el almacenamiento del navegador; funciona mejor desde una URL HTTPS estable.
